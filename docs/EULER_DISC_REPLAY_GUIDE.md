## 2. Quick Start: Software-Only Minimal Tutorial

### 2.1 Preview / Fast Convergence Check
To run the five-rung convergence diagnostic:
```bash
cargo run -p fs-euler-disc-e2e --bin euler_disc_campaign -- --convergence-only
```

### 2.2 Running the Campaign Manifest Runner
The standalone manifest runner validates all 12 mandatory core simulation rungs:
```bash
# Check manifest schema and case membership

# List all core and optional cases
scripts/ci/euler_disc_e2e.sh --list

# Run synthetic self-test suite
scripts/ci/euler_disc_e2e.sh --self-test
```

### 2.3 Executing the Full Numerical Campaign
To execute the deterministic 32-second horizon numerical simulation:
```bash
scripts/e2e/euler_disc_campaign.sh \
  --output target/euler-disc-campaign/campaign.jsonl \
  --stderr-log target/euler-disc-campaign/campaign.stderr.log
```

## 6. Troubleshooting & Common Diagnostics

| Diagnostic Code | Symptom / Cause | Recommended Fix |
|---|---|---|
| `NegativeThickness` | `thickness_m <= 0.0` in `DiscProfileSpec` | Provide strictly positive axial thickness |
| `OversizedFillet` | Fillet radius exceeds half thickness | Ensure `fillet_radius_m < thickness_m / 2.0` |
| `SingularInitialAlpha` | Nutation angle $\alpha < 0.5^\circ$ | Choose valid launch nutation $1^\circ \le \alpha \le 30^\circ$ |
| `ReplayDigestMismatch` | Artifact payload modified after sealing | Re-generate or restore original signed bundle |
